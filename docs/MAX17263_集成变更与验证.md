# SmartBattBox MAX17263集成变更与验证

## 配置和首次运行

入口仍为 SensorTask -> mod_battery_init/handler。纯寄存器层为 BSP/Driver/Src/drv_max17263.c；电池应用、学习日志及RTOS适配合并在 Module/Src/mod_battery.c，公开接口见 mod_battery.h/app_battery.h。驱动接口统一采用 drv_max17263_* 前缀（例如 drv_max17263_initialize、drv_max17263_sample），工程内调用已迁移。

集中配置：Module/Inc/battery_config.h。已确定8S、1mΩ、CELLX硬件分压1/20、内部温度、12灯。保留原工程20Ah、1A终止、2.5V空电/3V恢复、3.7V过压、10A充电/42A放电作为待确认参数；不是实物认证。ModelID=6，未提供实电芯定制模型时持续标记BAT_WARN_UNCHARACTERIZED。容量型SOH不能替代实测健康度。

首次升级必须使MAX17263完整断电再上电：旧固件曾错误写VEmpty及ModelCfg，MCU复位不等于电量计POR。新驱动暖启动会校验持久配置，不匹配报M_EPROFILE并5秒重试，禁止偷偷覆盖学习容量。单独温度选择变化允许读改写，不重置容量。HALT后重新烧录不是电量计断电。

内部温度为芯片die温度，应用不会将其作为电芯过温动作依据；原mod_temp和独立BMS温度保护保留。TH未接NTC的硬件处理仍需按数据手册核对。

## 数据/接口

battery_get_snapshot复制一致快照，valid=false或超过3500ms不用于控制。整包电压mV、电流int32 mA、充正放负，RepSOC/RepCap为报告口径。平均电流另有字段；温度0.1℃；cycles_raw以0.01等效循环为单位；TTE/TTF各有valid标志。故障历史与当前故障分开。主任务对持续2秒的数据失效或方向相关电压/电流故障断开电池通路并进入FAULT（充电检查过压/充电过流；放电检查欠压/放电过流，欠压允许充电恢复），进入充放电前也检查数据；这是额外软件联锁，不代替BMS。阈值和2秒延时需按实物系统确认。

BLE:新增battery_valid；电压仍为vbat但现在是整包mV；cur为32位mA；原temp键改为die_temp，手机解析需同步。屏幕0x2030显示BAT DATA INVALID，SOC数字清零；无效提示不能解释为真实0%电量。电池数据恢复时清该文本区域。

LED由SensorTask串行处理。mod_battery_led_mask(0xFFF)全亮，0全灭，1u<<n单灯(bit0..11=D17..D28)，mod_battery_led_soc恢复SOC。接口返回的是请求被接受，处理结果见快照last_error；单槽邮箱以最新请求为准。12灯固定计数、DNC保留，默认亮度8/31及VLED=2.0V仍需实物核实。

## 学习参数保存

W25Q128第9/10扇区：0x009000..0x00AFFF，共8KiB，专用于电池；避开现有配置0、日志1..8、标定255。未使用MCU内部第11扇区。内部Flash链接长度同时限制为896KiB，防止程序占用已有系统参数区；Keil散布文件同步。此次不烧录、不擦除任何硬件。

64字节记录包含magic/格式版本/序号/配置摘要/电池ID/RComp0/TempCo/FullCapRep/FullCapNom/Cycles/CRC/最后提交字。只选择完整记录；扇区轮换先保留最新有效记录所在扇区。SPI错误不会作为0xFF空白内容接受；写/擦均有回读校验。使用存储互斥锁，未来新增W25Q用户必须通过同一存储层，不可直接并发调用底层驱动。

首次有效采样60秒后建立记录；后续Cycles跨64个原始计数(0.64次)区间且距上次至少60秒保存。正常关机由AppMainTask请求SensorTask保存，最多等待2秒；60秒内已保存则合并请求，不能承诺最后几秒所有学习变化都已写入。突然掉电靠上一条周期记录恢复。写失败保留旧记录并设置BAT_FAULT_NVM。Flash缺失不阻断采样，但有NVM故障。battery_id在更换实物电池时必须改变；配置摘要变化拒绝旧记录。

完整恢复仅在POR发生后进行。MCU单独复位不拿Flash旧记录覆盖芯片当前学习状态。基础LFP模型的学习恢复流程仍需实板掉电验证，不能用仿真证明算法精度。

## 测试和充放电记录

主机回归测试执行真实ARM核心代码，覆盖初始化、错误注入、16个提交中断位置、CRC/配置匹配、12灯及应用故障。额外覆盖内部温度暖切换、VEmpty=0x7D4B、25.6V总压和-42A。测试记录另见验证结果；没有连接电池实测。

启用BATTERY_CSV_ENABLE=1，串口每秒输出两类CSV(仍有日志前缀)：
- BATCSV: timestamp,valid,pack_mV,current_mA,avg_current_mA,die_0.1C,SOC_percent,RepCap_mAh,FullCapRep_mAh,Cycles_raw,active_faults,last_error。
- BATDIAG: timestamp,diagnostic_read_error,Status,FStat,MixSOC_raw,VFSOC_raw,RComp0_raw,TempCo_raw,FullCapNom_mAh。diagnostic_read_error非0时该行诊断字段无效。

先用独立仪表校准电压、电流和零点；使用独立电池温度测量。按电芯/BMS限制完成室温静置、正常充满、满充静置、代表性负载放电至规定截止、空电静置、再次充满。记录参考Ah/Wh、终止原因及SOC误差。不得为了追到0%继续越过BMS/电芯截止条件。

必须另外测试：MCU单独复位、MAX单独POR、I2C断线恢复、W25Q失联、写入中断/CRC损坏/扇区轮换、参数或电池ID变化、继电器故障联锁和12灯流水。真实SOC精度、循环寿命/健康度、外部Flash实际掉电行为均尚未验证。
