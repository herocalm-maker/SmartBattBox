# AC通路控制实现说明（含PD7主接触器）

## 接线前提

本次按用户指定试验顺序，PD4先打开500ms，再打开PD7，100ms后打开PD0；运行中PD4和PD7持续保持。硬件前提仍需验证：外部直流主接触器连接 B+ 与 INV+，吸合后旁路 RE5/RT1 预充支路。原理图没有完整绘出外部主触点连接，烧录后带载运行前需核实实物。软件命令状态不是触点反馈；当前采用PD4等待500ms、PD7等待100ms，无直流电压/辅助触点闭环确认。

## 逆变与旁路

- 无有效市电且输入检测结果明确、电池和温度允许时，ACOUT开启逆变：断开冲突通路并等待释放 → PD4=1 → 等待500ms → PD7=1 → 等待100ms → PD0=1接负载。
- 正常逆变PD7、PD4、PD0均为高。PD1、PD2、PD3为低。
- 正常停止：PD0=0 → 等待交流继电器释放 → PD4=0 → PD7=0（连续发出命令） → 等待主接触器释放。取消直流稳定等待阶段也按同一流程执行。
- 逆变启动中或运行中确认有效市电，自动退出逆变并转PD1旁路，不自动开启充电。PD1必须等PD0释放、PD4/PD7关闭及接触器释放等待完成后才开启。
- 旁路失电/超范围/数据未知时关闭输出，不自动反切逆变；再次按ACOUT可在输入明确无效且保护允许时开启逆变。
- 故障立即撤销所有输出命令，取消后续启动动作；正常停止与紧急故障的断电策略不同。

## 按键

- ACIN、ACOUT再按关闭，再按开启；长按不会再触发一次切换。
- ACIN开启需要有效输入电，缺少有效输入时急促短响3声（150ms响/150ms间隔），不锁存开启请求。ACIN开启仍进入仅充电，关闭原有输出。
- ACIN充电启动：PD2=1 → 等待1500ms并检查条件 → PD3=1。
- 充电中开启ACOUT：保留PD2/PD3，只打开PD1。充电+旁路下ACOUT关闭只关PD1；ACIN关闭先关PD3，等待50ms再关PD2，保留PD1。
- ONOFF连续按住满3000ms（从首次采到本次稳定手势开始计时）触发有序关机。使用HAL毫秒时钟，不依赖轮询次数；未满3秒松开不触发，持续按住只触发一次。
- 关机先关闭AC输出和充电电池侧，等待50ms，再关闭PD4/PD7等输入，等待100ms，然后保存电池数据（最多约2秒）并拉低PB4。3秒是触发关机的门限，不承诺3秒时整板电源立即消失。硬件按键保持支路可能需松开按钮后才实际掉电。

## 时间参数（需上板验证）

均位于 App/Src/app_main_task.c，可分别调整：

| 参数 | 默认值 |
|---|---:|
| PATH_RELEASE_MS：交流/普通继电器释放 | 50ms |
| PATH_CONTACTOR_RELEASE_MS：PD7释放等待 | 100ms |
| PATH_PRECHARGE_MS：PD4打开后等待 | 500ms |
| PATH_INVERTER_START_MS：PD7打开后等待 | 100ms |
| PATH_CHARGER_START_MS：充电器启动 | 1500ms |
| PATH_INPUT_WAIT_MS：启动阶段输入未知最大等待 | 5000ms |

直流稳定等待期间不打开PD0；PD7/PD4在运行中持续保持高电平。正常切换均非阻塞，源检测或保护变化会取消待执行动作。

## 输入检测与保护

输入范围90～300V（含边界），连续2次有效范围内采样才确认有市电；范围外首次成功采样即撤销旁路许可。读取失败、负值、非有限数或超过2500ms未更新为UNKNOWN，不视作无市电。原HLW8110约1秒采集周期保留，不提供无缝UPS承诺。

电池数据无效、相关欠压/过流或温度保护可拒绝逆变。加入PD7并不取消这些保护。无市电按ACOUT仍被拒绝时，应检查输入UNKNOWN和电池/温度日志，不能只看输出图标。

充电方向保护覆盖充电+旁路；逆变保护覆盖PD7/PD4供电等待及运行阶段。保留频率采集、失败清零和电池保护恢复行为。驱动禁止旁路/充电与任意逆变支路同时开启，并要求先PD4再PD7，PD7和PD4都已打开才能打开PD0，稳定延时由主任务控制。

生产控制器、继电器驱动、输入分类器和实际按键扫描器通过ARM仿真执行；硬件、RTOS及其他服务使用模拟。运行：

```powershell
python tools/test_power.py --out <项目以外的测试输出目录>
```
