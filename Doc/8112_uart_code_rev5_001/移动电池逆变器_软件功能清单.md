## 一、系统概述

### 1.1 硬件架构总览

| 子系统 | 核心器件 | 说明 |
|--------|----------|------|
| 主控 MCU | STM32F407VGT6 (Cortex-M4, 168MHz) | 系统核心控制单元 |
| 电源系统 | TPS5430 (DC-DC) + HT7533-1 (LDO) × 3 | 24V→12V→5V→3.3V 多路供电 |
| 输入电能计量 | HLW8110 (U8) + ZMPT107-1 电压互感器 + ZEMCT131 电流互感器 | AC220V 输入侧功率计量 |
| 输出电能计量 | HLW8110 (U9) + ZMPT107-1 电压互感器 + ZEMCT131 电流互感器 | AC220V 输出侧功率计量 |
| 电池电量计 | MAX17263LETD+ (U19) | 磷酸铁锂电池组 SOC/SOH 监测 |
| 蓝牙模组 | PB-03F (U11) | 无线通信，手机 APP 连接 |
| 显示屏 | 串口屏 (UART4) | 本地人机交互界面 |
| 充电器 | 外置 29.2V 充电器 | 通过继电器控制充电输入 |
| 逆变器 | 外置逆变器模块 | DC→AC 220V/50Hz 转换 |
| 调试接口 | SP3232E (U10, RS232) + SWD | PC 调试与程序下载 |

### 1.2 系统工作模式

```
AC输入 → [输入计量] → 继电器矩阵 → [AC直通输出] / [充电器] → [电池组] → [逆变器] → [输出计量] → AC输出
                                      ↑                              ↑
                                  继电器控制                     继电器控制
```

- **AC 直通模式**：市电正常时，AC 输入直接通过继电器切换到 AC 输出
- **充电模式**：AC 输入经继电器切换至充电器，对磷酸铁锂电池组充电（29.2V）
- **逆变模式**：电池组经逆变器转换为 AC 220V/50Hz 输出
- **旁路模式**：市电断电时自动切换为逆变输出（UPS 功能）

## 三、各功能模块详细控制逻辑

### F01 — 系统初始化与自检

**涉及的硬件引脚**：NRST, BOOT0, BOOT1, 各路电源

**初始化流程**：

```
上电 → 电源建立 (24V→12V→5V→3.3V)
     → MCU 复位释放 (NRST)
     → 系统时钟初始化 (HSE 8MHz → PLL 168MHz)
     → GPIO 初始化 (默认安全状态：所有继电器断开)
     → 外设初始化 (UART1/2/3/4/6, I2C1, ADC, SPI2, TIM)
     → 看门狗初始化 (IWDG)
     → 自检序列：
        1. 读取电池电量计 (I2C1) → 校验通信正常
        2. 读取输入电能计量 IC (UART2) → 校验通信正常
        3. 读取输出电能计量 IC (UART3) → 校验通信正常
        4. ADC 采样各通道 → 校验数值范围
        5. 蓝牙模组初始化 → 等待就绪
        6. 显示屏初始化 → 发送启动画面
     → 自检通过 → 进入正常工作循环
     → 自检失败 → 蜂鸣器报警 + LED 闪烁故障码
```

**EARS 需求表述**：

- **(Ubiquitous)** The system shall perform a full self-test sequence on every power-on reset before enabling any power output.
- **(Unwanted)** If any self-test item fails, then the system shall enter fault mode, disable all output relays, and indicate the fault code via LED and buzzer.
- **(Event-driven)** When the self-test completes successfully, the system shall transition to standby mode and wait for user input.

### F02 — 开关机控制与电源管理

**涉及的硬件引脚**：

| 信号名 | GPIO | 方向 | 功能 |
|--------|------|------|------|
| KEY_ONOFF_IN | — | INPUT | 开关机按键输入 |
| PB3_ONOFF_KEY | PB3 | INPUT | 开关机按键检测 |
| PB4_PWR_EN | PB4 | OUTPUT | 电源使能（自锁供电） |
| PB5_CHG_WKUP | PB5 | OUTPUT | 充电器唤醒信号 |
| PA2_BLE_WKUP | PA2 | OUTPUT | 蓝牙唤醒信号 |

**开机逻辑**：

```
关机状态下短按 ON/OFF 键
  → MCU 检测 PB3 上升沿
  → 拉高 PB4_PWR_EN (自锁供电，松开按键后不掉电)
  → 执行系统初始化与自检
  → 进入待机模式
  → 显示屏点亮，显示主界面
```

**关机逻辑**：

```
运行状态下长按 ON/OFF 键 (≥3秒)
  → 显示屏弹出关机确认对话框
  → 用户确认后：
      1. 断开所有输出继电器 (AC输出/逆变器/充电器)
      2. 保存运行数据到 Flash
      3. 发送关机指令到蓝牙模组
      4. 延时 500ms
      5. 拉低 PB4_PWR_EN (断开自锁供电)
  → 系统完全断电
```

**EARS 需求表述**：

- **(Event-driven)** When a short press on the ON/OFF key is detected while the system is powered off, the system shall latch PB4_PWR_EN high and initiate the boot sequence.
- **(Event-driven)** When a long press (≥3s) on the ON/OFF key is detected while the system is running, the system shall prompt the user for shutdown confirmation, then safely disconnect all outputs before releasing the power latch.
- **(State-driven)** While the system is in normal operation, the system shall maintain PB4_PWR_EN high to keep the power supply latched.

### F03 — AC 输入/输出电能计量

**涉及的硬件**：

| 功能 | IC | 通信接口 | MCU 引脚 |
|------|-----|---------|----------|
| 输入电能计量 | HLW8110 (U8) | UART2 | PD5_UART2_TX, PD6_UART2_RX |
| 输出电能计量 | HLW8110 (U9) | UART3 | PD8_UART3_TX, PD9_UART3_RX |

**HLW8110 采集参数**：

| 参数 | 说明 | 单位 |
|------|------|------|
| 电压有效值 (VRMS) | AC 220V 经 ZMPT107-1 互感器采样 | V |
| 电流有效值 (IRMS) | 经 ZEMCT131 电流互感器采样 | A |
| 有功功率 (P) | 实时有功功率 | W |
| 功率因数 (PF) | cos φ | — |
| 累计电量 (EP) | 有功电能累计 | kWh |
| 频率 (FREQ) | 电网频率 | Hz |

**数据采集逻辑**：

```
定时器中断 (每 200ms)
  → UART2 发送读寄存器命令 → HLW8110 (U8) 输入侧
  → UART3 发送读寄存器命令 → HLW8110 (U9) 输出侧
  → 解析返回数据
  → 校验 CRC / 范围合理性
  → 更新全局数据结构：
      {
        input:  { Vrms, Irms, Power, PF, Energy, Freq },
        output: { Vrms, Irms, Power, PF, Energy, Freq }
      }
  → 计算系统效率 = output.Power / input.Power × 100%
  → 推送到显示屏更新
  → 推送到蓝牙数据通道
```

**EARS 需求表述**：

- **(Ubiquitous)** The system shall sample both input and output energy metering ICs (HLW8110) every 200ms via UART2 and UART3 respectively.
- **(Unwanted)** If communication with any HLW8110 fails for 3 consecutive attempts, then the system shall set the corresponding data as invalid, trigger an alarm, and log the fault event.
- **(State-driven)** While the system is in AC pass-through mode, the system shall calculate and display real-time efficiency as the ratio of output power to input power.

### F04 — 电池管理 (BMS)

**涉及的硬件**：

| 信号 | 器件/引脚 | 接口 | 功能 |
|------|----------|------|------|
| 电量计通信 | MAX17263LETD+ (U19) | I2C1 (PB6_SCL, PB7_SDA) | SOC/SOH/电压/电流 |
| 电量计报警 | PB8_GUAGE_ALRT | GPIO INPUT | 电量计异常中断 |
| 电池温度 | PA5_BAT_TMP_AD5 | ADC12_IN5 | NTC 温度采样 |
| 充电器温度 | PA4_CHG_TMP_AD4 | ADC12_IN4 | NTC 温度采样 |
| 逆变器温度 | PA6_INV_TMP_AD6 | ADC12_IN6 | NTC 温度采样 |
| 电池电压 | PA3_CHG_VOL_AD3 | ADC12_IN3 | 分压采样 (辅助) |

**MAX17263 采集参数**：

| 参数 | 说明 | 典型范围 |
|------|------|---------|
| SOC | 荷电状态 | 0% ~ 100% |
| SOH | 健康状态 | 0% ~ 100% |
| VCELL | 电芯电压 | 磷酸铁锂: 2.5V~3.65V |
| IBAT | 充放电电流 | — |
| TEMP | 内部温度 | -20°C ~ 85°C |
| TTE/TTF | 充放剩余时间 | — |
| CYCLES | 循环次数 | — |

**电池保护阈值**：

| 保护项 | 阈值 | 动作 |
|--------|------|------|
| 过充电压 | > 29.2V (电池组) | 断开充电继电器 RE4 |
| 过放电压 | < 20.0V (电池组) | 断开逆变器继电器 RE5，进入低功耗 |
| 充电过流 | > 额定值 120% | 断开充电继电器 RE4 |
| 放电过流 | > 额定值 120% | 断开逆变器继电器 RE5 |
| 充电高温 | > 50°C (NTC) | 断开充电继电器 RE4 |
| 放电高温 | > 60°C (NTC) | 断开逆变器继电器 RE5 |
| 充电低温 | < 0°C (NTC) | 禁止充电（磷酸铁锂低温保护）|
| 放电低温 | < -10°C (NTC) | 禁止逆变输出 |
| 电量过低 | SOC < 5% | 断开逆变输出，仅保留 MCU 供电 |

**电量计数据采集**：

```
I2C1 读取循环 (每 500ms)
  → 读取 MAX17263 寄存器：
      - SOC (0x06)
      - VCELL (0x09)
      - Current (0x0A)
      - Temperature (0x08)
      - TTE/TTF (0x11/0x20)
      - SOH (0x1F)
      - Cycles (0x17)
  → CRC 校验
  → 更新全局电池状态结构
  → 检查保护阈值
  → 触发保护动作 (如有)
  → 推送至显示和蓝牙
```

**EARS 需求表述**：

- **(Ubiquitous)** The system shall read battery SOC, voltage, current, and temperature from the MAX17263 fuel gauge via I2C1 every 500ms.
- **(Event-driven)** When any battery protection threshold is exceeded, the system shall immediately disconnect the corresponding relay and notify the user via display and buzzer.
- **(State-driven)** While SOC is below 5%, the system shall disable inverter output and enter low-power mode, maintaining only MCU operation and LED indication.
- **(Unwanted)** If I2C1 communication with MAX17263 fails for 5 consecutive attempts, then the system shall use ADC-based voltage readings as fallback and trigger a fuel gauge fault alarm.

### F05 — 继电器控制与模式切换

**继电器清单**：

| 编号 | 继电器 | 控制信号 | 驱动方式 | 功能 |
|------|--------|---------|----------|------|
| RE1 | G2RL-2-DC12 | PD1_AC_CTRL | Q2 (S8050) + 光耦 PC817 | AC 直接输出控制 |
| RE2 | G2RL-2-DC12 | PD2_CHG_IN | Q1 (S8050) + 光耦 PC817 | 充电器 AC 输入控制 |
| RE3 | G2RL-2-DC12 | PD0_INV_OUT | Q3 (S8050) + 光耦 PC817 | 逆变器 AC 输出控制 |
| RE4 | G2RL-2-DC12 | PD3_CHG_OUT | Q14 (S8050) + 光耦 PC817 | 充电器 DC 输出至电池 |
| RE5 | G2RL-2-DC12 | PD4_INV_PRO | Q15 (S8050) + 光耦 PC817 | 逆变器 DC 输入控制 |

> 继电器线圈供电：+12V_RL（由 +12V 电源经开关控制）

**模式切换逻辑（状态机）**：

```
                    ┌──────────────────────────────┐
                    │        系统待机 (STANDBY)       │
                    │   所有继电器断开，仅 MCU 运行     │
                    └──────┬──────────────┬─────────┘
                           │              │
              市电正常 + 用户选择    市电断开 + 电池OK
                           │              │
                           ▼              ▼
              ┌──────────────────┐  ┌──────────────────┐
              │  AC 直通模式      │  │  逆变输出模式      │
              │  RE1=ON          │  │  RE3=ON, RE5=ON   │
              │  (RE2/RE3/RE4/   │  │  (RE1/RE2/RE4=OFF)│
              │   RE5=OFF)       │  │                   │
              └────────┬─────────┘  └────────┬──────────┘
                       │                     │
              市电断开 (UPS)                  市电恢复
                       │                     │
                       ▼                     ▼
              ┌──────────────────┐  ┌──────────────────┐
              │  自动切换逆变     │  │  自动切回直通     │
              │  (断电检测延迟)   │  │  (来电检测延迟)   │
              └──────────────────┘  └──────────────────┘

              ┌──────────────────┐
              │  充电模式         │
              │  RE2=ON, RE4=ON  │
              │  (RE1/RE3/RE5=   │
              │   OFF)           │
              └──────────────────┘
```

**继电器切换互锁规则**：

| 规则 | 说明 |
|------|------|
| 互锁 1 | RE1 (AC 直通) 和 RE3 (逆变输出) 不能同时闭合（输出冲突）|
| 互锁 2 | RE2 (充电 AC) 和 RE1 (AC 直通) 可以同时闭合（边充边放）|
| 互锁 3 | RE4 (充电 DC) 闭合前必须确认 RE2 已闭合且充电器电压正常 |
| 互锁 4 | RE5 (逆变 DC) 闭合前必须确认 RE3 已闭合且电池 SOC > 5% |
| 切换延时 | 任何继电器状态切换必须间隔 ≥ 100ms（防电弧）|

**UPS 自动切换逻辑**：

```
监测输入电压 (HLW8110 U8)
  → 当 V_in < 180V (断电阈值) 持续 20ms：
      1. 断开 RE1 (切断 AC 直通)
      2. 延时 10ms (确保断开)
      3. 闭合 RE5 (接通逆变器 DC 输入)
      4. 延时 500ms (等待逆变器稳定)
      5. 闭合 RE3 (接通逆变器 AC 输出)
      6. 标记系统为逆变模式
  → 当 V_in > 200V (来电阈值) 持续 3s：
      1. 断开 RE3 (切断逆变输出)
      2. 延时 10ms
      3. 断开 RE5 (切断逆变器 DC)
      4. 延时 10ms
      5. 闭合 RE1 (接通 AC 直通)
      6. 标记系统为直通模式
```

**EARS 需求表述**：

- **(Ubiquitous)** The system shall enforce relay interlock rules to prevent any condition where both AC pass-through (RE1) and inverter output (RE3) relays are simultaneously closed.
- **(Event-driven)** When the AC input voltage drops below 180V for more than 20ms, the system shall automatically switch from pass-through mode to inverter mode within 600ms.
- **(Event-driven)** When the AC input voltage rises above 200V and remains stable for 3 seconds, the system shall automatically switch back from inverter mode to pass-through mode.
- **(Unwanted)** If any relay state feedback does not match the commanded state within 100ms, then the system shall declare a relay fault, disconnect all outputs, and alert the user.

### F06 — 逆变器控制

**涉及的硬件引脚**：

| 信号 | GPIO | 方向 | 功能 |
|------|------|------|------|
| PD4_INV_PRO | PD4 | OUTPUT | 逆变器 DC 输入继电器控制 (RE5) |
| PD0_INV_OUT | PD0 | OUTPUT | 逆变器 AC 输出继电器控制 (RE3) |
| PD7_INV_IN | PD7 | — | 逆变器输入控制信号 |
| PA6_INV_TMP_AD6 | PA6 | ADC IN | 逆变器温度检测 |

**控制逻辑**：

```
逆变器启动条件检查：
  ✓ 电池 SOC > 5%
  ✓ 电池电压 > 20V
  ✓ 逆变器温度 < 60°C
  ✓ 无系统故障
  ✓ RE1 已断开 (互锁)

启动流程：
  1. 拉高 PD4_INV_PRO → Q15 导通 → RE5 闭合 (DC 输入)
  2. 延时 500ms → 等待逆变器 DC 侧稳定
  3. 拉高 PD0_INV_OUT → Q3 导通 → RE3 闭合 (AC 输出)
  4. 确认输出计量 IC 检测到正常电压 (220V ± 10%)
  5. 标记模式 = 逆变输出

停止流程：
  1. 拉低 PD0_INV_OUT → RE3 断开 (AC 输出)
  2. 延时 10ms
  3. 拉低 PD4_INV_PRO → RE5 断开 (DC 输入)
  4. 标记模式 = 待机
```

**EARS 需求表述**：

- **(Event-driven)** When an inverter start command is received (manual or UPS auto-switch), the system shall first verify all start conditions, then close RE5 (DC input) followed by RE3 (AC output) with a 500ms stabilization delay.
- **(State-driven)** While the inverter is running, the system shall continuously monitor inverter temperature via PA6_ADC. If temperature exceeds 60°C, the system shall increase fan speed; if it exceeds 70°C, the system shall shut down the inverter.

### F07 — 充电器控制

**涉及的硬件引脚**：

| 信号 | GPIO | 方向 | 功能 |
|------|------|------|------|
| PD2_CHG_IN | PD2 | OUTPUT | 充电器 AC 输入继电器控制 (RE2) |
| PD3_CHG_OUT | PD3 | OUTPUT | 充电器 DC 输出继电器控制 (RE4) |
| PA3_CHG_VOL_AD3 | PA3 | ADC IN | 充电器电压检测 |
| PA4_CHG_TMP_AD4 | PA4 | ADC IN | 充电器温度检测 |

**充电策略（磷酸铁锂电池，6S）**：

```
充电阶段：
  CC (恒流) → CV (恒压) → 涓流 → 停止

充电启动条件：
  ✓ 市电正常 (V_in > 200V)
  ✓ 电池 SOC < 100%
  ✓ 电池温度 0°C ~ 50°C
  ✓ 充电器温度 < 50°C
  ✓ 无系统故障

启动流程：
  1. 拉高 PD2_CHG_IN → RE2 闭合 (充电器 AC 供电)
  2. 延时 2s → 等待充电器输出稳定
  3. 读取 PA3_ADC → 确认充电器输出电压 29.2V ± 1V
  4. 拉高 PD3_CHG_OUT → RE4 闭合 (接通电池)
  5. 标记模式 = 充电中

充电终止条件 (任一满足)：
  - 充电电流 < C/20 (通过 MAX17263 读取)
  - 电池 SOC = 100%
  - 电池电压 ≥ 29.2V 且电流下降至截止值
  - 充电超时 (8小时)
  - 温度保护触发

停止流程：
  1. 拉低 PD3_CHG_OUT → RE4 断开 (先断电池侧)
  2. 延时 100ms
  3. 拉低 PD2_CHG_IN → RE2 断开 (再断 AC 侧)
  4. 标记模式 = 充电完成
```

**EARS 需求表述**：

- **(Event-driven)** When charging is initiated, the system shall first apply AC power to the charger (RE2), verify the charger output voltage reaches 29.2V, and then connect the battery (RE4).
- **(State-driven)** While charging, the system shall continuously monitor charge current via MAX17263. When current drops below C/20, the system shall terminate charging.
- **(Unwanted)** If the charger output voltage is outside the range of 28V~30V after RE2 closure, then the system shall abort charging, disconnect RE2, and trigger a charger fault alarm.

### F10 — 温度监测与保护

**涉及的硬件**：

| 信号 | ADC 通道 | 传感器 | 监测对象 |
|------|---------|--------|---------|
| PA4_CHG_TMP_AD4 | ADC12_IN4 | NTC (BAV99 保护) | 充电器温度 |
| PA5_BAT_TMP_AD5 | ADC12_IN5 | NTC (BAV99 保护) | 电池温度 |
| PA6_INV_TMP_AD6 | ADC12_IN6 | NTC (BAV99 保护) | 逆变器温度 |

**NTC 采样电路**：NTC 与 10K 固定电阻分压，接 BAV99 保护二极管

**温度计算**：

```
ADC 采样 → 电压值 → 计算 NTC 电阻值 → 查表/Steinhart-Hart 方程 → 温度值
```

**温度保护阈值**：

| 监测对象 | 预警阈值 | 保护阈值 | 恢复阈值 | 保护动作 |
|---------|---------|---------|---------|---------|
| 电池 | 48°C | 55°C (充) / 65°C (放) | 45°C | 断开对应继电器 |
| 充电器 | 45°C | 55°C | 42°C | 断开充电继电器 |
| 逆变器 | 55°C | 70°C | 50°C | 断开逆变继电器 |

**EARS 需求表述**：

- **(Ubiquitous)** The system shall sample all three NTC temperature sensors via ADC every 500ms and apply digital filtering (moving average, N=8).
- **(Event-driven)** When any temperature exceeds the protection threshold, the system shall immediately disconnect the corresponding subsystem and log the overtemperature event.

### F11 — 风扇控制

**涉及的硬件**：

| 信号 | GPIO | 控制方式 | 驱动器件 |
|------|------|---------|---------|
| PD10_FAN1_CTRL | PD10 | PWM | Q18 (YJL03N06A MOS) |
| PD11_FAN2_CTRL | PD11 | PWM | Q17 (YJL03N06A MOS) |

**风扇控制策略**：

```
风扇1 (FAN1) — 主散热风扇：
  温度 < 35°C → 关闭 (Duty = 0%)
  35°C ~ 50°C → 线性调速 (Duty = 30% ~ 100%)
  温度 > 50°C → 全速 (Duty = 100%)

风扇2 (FAN2) — 辅助散热风扇：
  逆变器运行时 → 开启 (Duty = 50%)
  充电时且温度 > 40°C → 开启 (Duty = 50%)
  其他情况 → 关闭
```

**EARS 需求表述**：

- **(State-driven)** While the system temperature is between 35°C and 50°C, the system shall linearly adjust FAN1 PWM duty cycle from 30% to 100%.
- **(Event-driven)** When the inverter starts, the system shall turn on FAN2 at 50% duty cycle.

- **(State-driven)** While the system is in normal operation, the green LED shall remain solid on. While in standby, it shall blink at 1Hz.
- **(Event-driven)** When a fault condition is detected, the system shall activate the red alarm LED and buzzer with a 100ms ON/OFF repeating pattern until the fault is cleared or acknowledged.

### F13 — 按键输入处理

**涉及的硬件**：

| 信号 | GPIO | 按键 | 功能 |
|------|------|------|------|
| PB0_ACIN_KEY | PB0 | S2 | AC 输入开关控制 |
| PB1_ACOUT_KEY | PB1 | S3 | AC 输出开关控制 |
| PB3_ONOFF_KEY | PB3 | S4 | 系统开关机 |
| KEY_ONOFF_IN | — | ON/OFF 按键 | 开关机 (电源电路联动) |

**按键处理逻辑**：

```

  → 去抖动 (3 次确认)
```

### F14 — 故障诊断与保护

**故障分级**：

| 级别 | 名称 | 系统响应 | 示例 |
|------|------|---------|------|
| F0 | 致命故障 | 立即全断开，锁死，需手动复位 | 继电器粘连、MCU 自检失败 |
| F1 | 严重故障 | 断开相关子系统，可自动恢复 | 过温保护、过流保护 |
| F2 | 一般故障 | 降功率运行，提示用户 | 通信异常、传感器故障 |
| F3 | 警告 | 仅记录和提示 | 电量低预警、温度偏高预警 |

**故障码定义**：

| 故障码 | 名称 | 级别 | 检测条件 |
|--------|------|------|---------|
| E001 | 电池过放 | F1 | V_bat < 20V |
| E002 | 电池过充 | F1 | V_bat > 29.2V |
| E003 | 充电过流 | F1 | I_chg > Imax × 1.2 |
| E004 | 放电过流 | F1 | I_dis > Imax × 1.2 |
| E005 | 电池高温 | F1 | T_bat > 55°C (充) / 65°C (放) |
| E006 | 逆变器高温 | F1 | T_inv > 70°C |
| E007 | 充电器高温 | F1 | T_chg > 55°C |
| E008 | 电池低温 | F1 | T_bat < 0°C (充) / < -10°C (放) |
| E009 | 输入计量通信故障 | F2 | UART2 连续 3 次无响应 |
| E010 | 输出计量通信故障 | F2 | UART3 连续 3 次无响应 |
| E011 | 电量计通信故障 | F2 | I2C1 连续 5 次无响应 |
| E012 | 继电器故障 | F0 | 状态反馈不匹配 |
| E013 | 逆变器输出异常 | F1 | 输出电压超出 220V ± 15% |
| E014 | 充电器输出异常 | F1 | 充电器电压超出 29.2V ± 2V |
| E015 | 输入过压/欠压 | F2 | V_in > 260V 或 < 180V |
| E016 | 系统过载 | F1 | P_out > 额定功率 × 1.1 |

**EARS 需求表述**：

- **(Ubiquitous)** The system shall maintain a fault code register that records the last 20 fault events with timestamps in non-volatile memory.
- **(Event-driven)** When a Level F0 fault is detected, the system shall immediately disconnect all relays, enter a locked state, and require a manual reset via long press of the ON/OFF key.
- **(State-driven)** While a Level F1 fault is active, the system shall automatically attempt recovery after the fault condition clears and a 30-second cooldown period elapses.

### F17 — OTA 固件升级

**升级流程**：

```
手机 APP → 蓝牙发送固件包 → PB-03F 接收 → UART6 → MCU
  → MCU 校验固件 (CRC / 签名)
  → 校验通过 → 写入 Flash (IAP 分区)
  → 写入完成 → 设置启动标志
  → 软件复位 → Bootloader 引导新固件
  → 升级失败 → 回滚至原固件
```
