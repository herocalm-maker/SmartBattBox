# 2026-06-03

## 修复 HLW8112 reader 重复打印 bug

- **问题**：主循环中 `HLW811X_LOG_MeterData()` 打印的数据重复出现两次。
- **根因**：`hlw8112_reader.c` 的 `COMPLETE` 状态仅将 state 切回 `IDLE`，但未清除 `g_hlw811x_reader_ready` 标志，导致下一轮主循环 `IsReady()` 仍返回 1，从而重复输出上一次的旧数据。
- **修复**：在 `COMPLETE` 分支新增 `g_hlw811x_reader_ready = 0;`，确保每轮测量完成后 ready 标志立即清除。

## HLW8112 头文件分层重构

将臃肿的 hlw8112.h（537行，7种职责混杂）拆分为清晰分层：

- **新建 hlw8112_regs.h**：寄存器地址 + SYSCON/EMUCON/EMUCON2 位定义 + 命令协议（来自芯片数据手册，约250行）
- **新建 hlw8112_log.h**：HLW811X_LOG_* 日志函数声明（约50行）
- **新建 hlw8112_calib.h**：D_CAL_* / D_K1 / D_K2 校准系数宏（约30行）
- **重构 hlw8112.h**：537行→130行，成为纯聚合入口，按分层顺序 include 子模块（config → hw → regs → calib → reader → log），顶部注释说明每个子文件职责
- **整理 hlw8112_internal.h**：收容所有内部函数声明（Clear_RxBuf, Uart_Read_HLW8110_Reg, checksum 等）、内部变量声明（U16_Check_SysconReg_Data, U16_CheckSUM_* 等），新增 #include "hlw8112.h" 解决类型依赖
- **清理重复定义**：D_REG_SYSCON/EMUCON/EMUCON2_DATA 统一定义在 hlw8112_config.h，删除 hlw8112.c 和 hlw8112_reader.c 中的重复

效果：新人打开 hlw8112.h 即可一眼看清整个驱动的分层结构和入口点。
