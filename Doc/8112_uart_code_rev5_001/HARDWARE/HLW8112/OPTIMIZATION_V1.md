# HLW8112 驱动时序与性能参考

> **本文件为重构前优化笔记的摘要**，保留时序数据供调试参考。
> 当前驱动版本为 V4.2（全局变量方案），API 命名已变更，时序特性不变。

## 系统配置

| 参数 | 值 |
|------|-----|
| MCU 主频 | 72 MHz (STM32F103) |
| UART2 (HLW8112) | 9600 bps, 偶校验, 每字节 1.042ms |
| UART1 (PC日志) | 460800 bps, 每字节 21.7μs |
| 定时器 TIM3 | 2ms/tick |

## 一轮完整读取耗时

| 寄存器 | 描述 | 接收字节 | 通信耗时 |
|:------:|------|:--------:|:--------:|
| RMSU | 电压 | 4 | 4.17 ms |
| RMSIA | A 相电流 | 4 | 4.17 ms |
| POWERPA | A 相功率 | 5 | 5.21 ms |
| ENERGYPA | A 相电能 | 4 | 4.17 ms |
| RMSIB | B 相电流 | 4 | 4.17 ms |
| POWERPB | B 相功率 | 5 | 5.21 ms |
| ENERGYPB | B 相电能 | 4 | 4.17 ms |
| POWERPS | 视在功率 | 5 | 5.21 ms |
| UFREQ | 频率 | 3 | 3.13 ms |
| ANGLE | 相角 | 3 | 3.13 ms |
| PF | 功率因数 | 4 | 4.17 ms |
| | **合计** | | **~46.9 ms** |

> 实际一轮 ~75ms（含调度开销），数据更新率约 **13 Hz**。

## 超时配置

| 波特率 | 超时 tick | 超时时间 |
|:------:|:---------:|:--------:|
| 9600 | 5 | 10ms |
| 19200 | 3 | 6ms |
| 38400 | 2 | 4ms |

## 错误恢复

超时或校验错误 → `g_hlw811x_reader_errors++` → 20ms 延时后跳过当前项 → 继续下一项。

## 数据输出

`HLW811X_Reader_GetData()` 已替换为直接读全局变量。日志打印通过 `HLW811X_HW_Print()`，主循环写入耗时 ~59μs（写入环形缓冲区），TXE 中断后台发送 ~12.8ms。

## 历史优化对比

| 指标 | 阻塞式 (V1.x) | 非阻塞 (V2+) |
|------|:-------------:|:------------:|
| 单轮读取 | ~180ms | ~75ms |
| 主循环阻塞 | 是 | 否 |
| 更新率 | ~5.5 Hz | ~13 Hz |
