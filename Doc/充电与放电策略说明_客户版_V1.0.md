# SmartBattBox 充电与放电策略说明

> 文档版本：V1.0　　发布日期：2026-11-24
> 适用产品：SmartBattBox 储能电源（8S 磷酸铁锂电池 / 1000W 逆变）
> 说明：本文描述设备在正常使用条件下的充放电行为与保护策略，供客户选型、使用与验收参考。

---

## 一、产品工作模式

设备根据市电状态自动切换两种工作模式，无需人工干预：

| 模式 | 触发条件 | 行为 |
|---|---|---|
| **市电模式** | 检测到 220V 输入 | 给电池充电；同时可旁路向负载供电 |
| **逆变模式** | 220V 断开 | 电池经逆变器向负载供电 |

输出通道（AC OUT）可以单独开关：

- **AC OUT 开**：市电模式走旁路输出，市电断电自动切逆变输出
- **AC OUT 关**：仅给电池充电，不对外供电

## 二、充电策略

### 2.1 自动充电启动条件

同时满足以下条件才启动充电：

1. 检测到 220V 输入并**稳定 2 秒**（防抖）
2. 电池电量 **SOC ≤ 97%**
3. 电池电压**低于 27.16V**（3.40V/单体）
4. 不在"充满后 10 分钟冷却期"内
5. 电池温度正常、无故障

> **迟滞设计**：电压回升到 **27.24V** 以上才撤销充电请求，避免在门限附近反复启停。

### 2.2 充电过程

标准三段式：

| 阶段 | 现象 |
|---|---|
| 恒流（CC） | 充电电流约 **6A**，电压缓慢上升 |
| 恒压（CV） | 电压升至 **29.2V**（3.65V/单体）后保持，电流逐渐下降 |
| 涓流 | 电流降到 1A 以下，进入判满流程 |

充电继电器时序：先接通充电器输入，**1.5 秒**后接通电池，避免浪涌。

### 2.3 充满判定

按优先级依次判断：

| 判据 | 条件 | 动作 |
|---|---|---|
| **A1（主判据）** | SOC = 100% **且** 库仑计充满标志 FQ = 1 **且** 剩余时间 = 0 | 立即停充 |
| **A2（强制）** | SOC = 100% 但 FQ/剩余时间未同时满足 | **5 分钟**后强制停充 |
| **B（物理兜底）** | 单体电压 ≥ 3.60V（28.8V）**且** 平均电流 ≤ 500mA，**连续保持 1 小时** | 停充 |

> 物理兜底用于库仑计无法准确判满的特殊情况（电池老化、容量学习偏差等）。

### 2.4 停充之后

| 项目 | 说明 |
|---|---|
| **冷却时间** | 停充后 **10 分钟**内不再启动充电 |
| **平时补电** | 冷却结束后，若 SOC ≤ 97% **且** 单体电压低于 3.40V 才补电 |
| **来电补满** | 220V 掉电再恢复后 **10 分钟内**，无论电量多少都会把电池补满 |
| **拔插解除** | 拔掉再插上 220V 视为用户主动要求充电，立即解除冷却 |

### 2.5 充电保护

| 保护项 | 门限 | 动作 |
|---|---|---|
| 电池过流（充电） | 9.6A | 停充并报错 |
| 电池过压 | 3.72V/单体（29.76V） | 停充并报错 |
| 电池过温 | **60℃** | 停充 + 停交流输出，**55℃** 自动恢复 |
| 充电器过温 | 60℃ 预警 / **75℃** 故障 | 停机 |
| 市电异常 | 电压超出 180~260V 窗口 / 掉电 | 转逆变或停机 |

## 三、放电（逆变输出）策略

### 3.1 启动条件

同时满足才允许启动逆变输出：

1. 无市电（逆变模式）
2. 用户按下 AC OUT 键（或市电断开时自动接管）
3. 电池电量 **SOC ≥ 1%**
4. 单体电压 **≥ 3.00V**（24.0V）

不满足时：3 声蜂鸣提示，屏幕显示 `LOWBAT` 闪烁，不输出。

### 3.2 启动时序（共 3.5 秒）

| 步骤 | 动作 | 时长 |
|---|---|---|
| ① | 预充电阻接通，给逆变器母线电容充电 | **1.5 秒** |
| ② | 主继电器吸合 | **0.5 秒** |
| ③ | 预充电阻断开（电池直连逆变器） | **1.5 秒** |
| ④ | 输出继电器吸合，对外供电 | — |

> 预充环节用于抑制浪涌电流，保护继电器触点与电池。

### 3.3 运行中的保护（按优先级）

#### ① 过载保护

| 门限 | 动作 |
|---|---|
| **> 500W** | 声光报警：蜂鸣 + 报警灯 + 屏幕 `OVERLOAD` 闪烁（**不停机**） |
| **> 700W 持续 30 秒** | 自动关闭输出 |
| **> 1000W 持续 3 秒** | 立即关闭输出 |

#### ② 电池欠压保护（三级）

| 级别 | 条件 | 动作 | 恢复条件 |
|---|---|---|---|
| **软停** | 单体 ≤ **2.80V**（22.4V） | 关闭输出 + `LOWBAT` 闪烁 + 3 声蜂鸣 | 单体 ≥ 3.00V **且** 冷却 2 分钟后可再开 |
| **硬停** | 单体 ≤ **2.70V**（21.6V） | 关闭输出 + 锁存 | 单体 ≥ 3.00V 自动解除 |
| 低电量 | SOC < 1% | 关闭输出 | SOC ≥ 1% 可再开 |

> **软停后 2 分钟内禁止重启**，避免"刚回弹就开、一开就跌穿"的反复启停。

#### ③ 其它保护

| 保护项 | 门限 | 动作 |
|---|---|---|
| 电池过温 | 60℃ | 停输出（55℃ 恢复） |
| 逆变器过温 | 75℃（60℃ 预警） | 故障锁死 |
| 输出通道异常 | 计量无数据 | 立即关闭输出 |
| 输出空载 | 功率 ≤ 1W 持续 **50 分钟** | 自动关闭输出（只关输出，不关机） |

### 3.4 停止时序

1. 断开输出继电器（对外停止供电）
2. 等待 **1.5 秒**，让逆变器卸载、母线电容放电
3. 断开主继电器与预充继电器（电池与逆变器完全隔离）

### 3.5 空闲管理

| 项目 | 条件 | 动作 |
|---|---|---|
| 输出空载 | 无负载 50 分钟 | 关闭 AC 输出 |
| 整机空闲 | 无输出、无充电 1 小时 | 整机自动关机 |

## 四、显示与提示

### 4.1 电量显示

| 电量 | 颜色 |
|---|---|
| ≥ 20% | 白色 |
| 10% ~ 20% | 橙色 |
| < 10% | 红色 |

电量数据无效时自动隐藏，不显示 `0%`。

### 4.2 告警文本（TextAlarm，第 2 行）

| 内容 | 触发 | 显示方式 |
|---|---|---|
| `LOWBAT` | 电池欠压/低电量导致逆变停输出 | **2.0 秒周期闪烁**（亮 1s / 灭 1s） |
| `OVERLOAD` | 输出功率 > 500W | 2.0 秒周期闪烁 |
| 空白 | 正常运行 | — |

### 4.3 故障代码（TextError，第 1 行）

| 代码 | 含义 | 是否自动恢复 |
|---|---|---|
| `ERR01` | 电池电量计通讯故障 | 恢复通讯后自动 |
| `ERR02` | 计量芯片通讯故障 | 恢复通讯后自动 |
| `ERR03` | 电池数据无效 | 数据有效后自动 |
| `ERR04` | 存储/参数异常 | 需检查 |
| `ERR10` | 电池过压（充电中） | 电压回落后自动 |
| `ERR11` | 电池欠压（放电中） | 电压回升后自动 |
| `ERR12` | 电池过流 | 电流回落后自动 |
| `ERR20` | 电池温度 ≥ 60℃ | **55℃ 自动恢复** |
| `ERR21` | 充电器温度 ≥ 75℃ | 需冷却后重启 |
| `ERR22` | 逆变器温度 ≥ 75℃ | 需冷却后重启 |
| `ERR40` | 市电异常（电压越窗） | 市电恢复后自动 |

> 低电量不显示错误码，只用 `LOWBAT` + 蜂鸣提示（按产品定义）。

## 六、使用注意事项

1. **长期存放**：建议存放在 20~40℃ 环境，电量保持在 40%~60%，每 3 个月补充电一次。
2. **首次使用**：电池可能处于低电量状态，接入 220V 后会自动充电，充满约需 4~5 小时。
3. **欠压停机后**：屏幕显示 `LOWBAT` 属正常保护，请接入 220V 充电，充电后自动恢复。
4. **过载报警**：出现 `OVERLOAD` 时请减少负载，长时间超载会自动断开输出。
5. **过温提示**：出现 `ERR20` 时设备会自动停止充放电，待温度降至 55℃ 以下自动恢复。
6. **环境要求**：请勿在潮湿、腐蚀性气体或强振动环境中使用。
