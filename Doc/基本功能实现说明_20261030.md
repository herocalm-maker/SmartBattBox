## 二、逐条实现说明

### 需求 1：未接负载显示 `--`

- 判据：`m->out_ok && m->vout_p_w > 1.0W` 视为接了负载（`TEXT_TIME_LOAD_W`，与需求"输出功率>1有负载"一致）。
- 显示形态由 `time_show_t` 三态管理（`TIME_SHOW_NONE / DASH / VALUE`），只在**状态变化时写屏**，不重复刷。
- 覆盖两种输出通路：`icon_out`（逆变）或 `icon_ups`（旁路）亮即视为输出中。
- 顺带修正：原先"估计未成熟"显示 `0 MIN`（会误导为 0 分钟），现统一显示 `--`。
- 时间图标（`0x200C`）同步扩展到旁路工况，避免出现"有 `--` 无图标"。

### 需求 3：过载两级

- 阈值集中在 `Board.h:270-272`：`ALARM_W=500` / `TRIP_W=700` / `TRIP_HOLD_MS=600000`。
- **告警**：`vout_p_w > 500W` → `s_overload_alarm=true`，三方同相：
  - 蜂鸣器：每 2.0s 周期上升沿短响一声（`drv_buzzer_short_sound(1)`，250ms）；
  - 报警灯：报警相位（1.0s 亮 / 1.0s 灭）；
  - 屏幕：`TextAlarm` 在报警相位写 `"OVERLOAD"`，静默相位写空 → 视觉 2.0s 闪动。
- **停机**：`vout_p_w > 700W` 连续 10min → 撤输出请求 + 2 声短鸣（功率回落到 700W 以下即复位计时）。
- 判据统一用原始值 `vout_p_w` 与 `m->out_ok`（旧代码保护用 `out_ok`、显示用 `online`，判据不一致已修）。
- 旧 `1100W / 5s` 立即停机逻辑**已按新需求移除**（不再保留"冲击兜底"，避免与新分级冲突）。

> 取消输出后不会自动重启，需重新按键（与原有行为一致）。

### 需求 4：温度分级

- **35℃ 联动**：风扇逻辑未改（`fan_manage`，35℃ 开 / 30℃ 关）；`Temp` 图标改为 **1.0s 周期闪动**（0.5s 亮 / 0.5s 灭），并补上与风扇一致的 5℃ 迟滞（35 亮 / 30 灭），消除临界抖动。
- **60℃ 降载**：`battery_over_temp_guard()`，`>=60.0℃` 触发、`<=55.0℃` 自动恢复：
  - 停充：走既有顺序断电（先断 `CHG_OUT`，1.5s 后断 `CHG_IN`）；
  - 停输出：撤销输出请求，由旁路/逆变状态机按各自时序断电；
  - 置 `SYS_ALARM_BAT_OTP` → 屏幕显示 `ERR08`；
  - 降载期间 ACOUT 按键被拒绝（3 声），`need_charge` 强制为 false。
- **与旧行为的关键差异**：旧代码 55℃ 走 `enter_fault()` **锁死**（必须断电重启）；现改为**可恢复降载**，温度回落即解除，不再锁死。

### 需求 6：免按键转逆变

- 根因：`work_status_process()` 中"AC 掉电守卫"先于模式决策执行，`input_abort()` → `power_abort()` 会**清除输出请求**，导致必须重按 AC 键。该守卫与 `input_abort()` 已删除。
- 现逻辑：`mode_decide()` 把 `AC_ABSENT` **和** `AC_UNKNOWN` 都判为"无市电"，只收敛市电侧通路（断充电/旁路），**保留 `ac_out_requested`**；逆变状态机按同一请求自动接管。
- `AC_UNKNOWN`（输入计量读失败/超期）按无市电处理：市电侧继电器必须全断，不允许把不可信的市电直通到输出端。
- 实际切换时间仍受硬件三段时序约束（预充 1.5s + 直连 0.5s + 稳定 1.5s ≈ 3.5s），且继电器的市电/逆变互锁会自动串行化"断充电 → 启逆变"。

### 需求 7：0.5h 空载关输出

- `AC_IDLE_STOP_MS = 1800000`（30min），`AC_IDLE_PWR_W = 1.0W`。
- **旁路与逆变统一**：旧逻辑只在逆变 `RUNNING` 检测且为 60s，旁路完全没有空载检测。现由 `output_running()`（旁路或逆变 RUNNING）统一判定，两通路共用同一计时器（二者互斥）。
- 接上负载（>1W）即复位计时；到时撤请求 + 2 声短鸣。

### 需求 8：1h 无供电无充电关整机

- 判定空闲 = 未故障 且 充电/旁路/逆变三个子状态机全 IDLE 且 无输出请求 且 无充电请求。
- 持续 1h → `system_shutdown("idle 1h: ...")`：断全部通路 → 熄灯/熄屏数据 → 灭电量 LED → 保存 checkpoint → `DEV_POWER_OFF()`。
- `system_shutdown()` 是**唯一断电出口**，ONOFF 长按与 1h 定时共用，避免两套关机流程并存（旧评审 P0-I1 的问题）。
- 故障锁死态不参与该计时（保留故障提示，等用户处理）。

### 3.2 需求 5（电量分色）：单控件 + 切 ICL 库

屏端只保留 **一个** `ArtisticVarBattPer`（VP `0x5100`，SP `0x5188`），另两个叠加控件删除。数字与颜色两条通道：

| 内容 | 写哪里 | 何时写 |
| --- | --- | --- |
| 电量数值 | VP `0x5100` | 每 500ms |
| 颜色（ICL 库） | **SP+4 = `0x518C`**，高字节=库号、低字节=`0x00`（透明模式） | 仅跨档时写 |

| SOC | 库号 | ICL 文件 | 写入值 |
| --- | --- | --- | --- |
| ≥ 20% | `0x31`(49) | 49_b_num.icl | `0x3100` |
| 10% ~ 20% | `0x33`(51) | 51_b_num_orange.icl | `0x3300` |
| < 10% | `0x34`(52) | 52_b_num_red.icl | `0x3400` |

```c
/* 跨档时切库 */
uint16_t lib = (soc_level == 0) ? LIB_BATT_WHITE
             : (soc_level == 1) ? LIB_BATT_ORANGE : LIB_BATT_RED;
drv_dwin_set_value(VP_BATT_SOC_LIB /* 0x518C */, (int16_t)(lib << 8));

/* 数值每拍刷新 */
drv_dwin_set_value(VP_BATT_SOC, soc);
```

> 该方案同时输出档位值到 `0x202A`（供屏端 OS 核方案备用）。
> **屏端前置条件**：必须删除 `ArtisticVarBattPer_orange`(0x5120) 与 `ArtisticVarBattPer_Red`(0x5126)，
> 否则它们会显示各自 VP 的残留数字，与主控件叠加。

阈值在 `Board.h` 的 `BOARD_SOC_COLOR_ORANGE_PCT` / `BOARD_SOC_COLOR_RED_PCT`（20 / 10）。

### 3.3 风扇显示逻辑

- 判据：`app_ui_fan_running()` = 主风扇**或**辅风扇已开启（`fan_manage()` 按 35/30℃ 迟滞控制）。
- 完全按实际风扇状态显示，无风扇运行则动画失能隐藏（正式版无上电自检）。
- 两个控件同时驱动，**只做使能**，播放相位由控件自己负责：
  - `VarIconFan (0x200A)`：有风扇 `1`（显示），无风扇 `0`（0 号为空图标，不显示）；
  - `AnimationFan (0x510E)`：有风扇 `1`（使能显示，控件自动播放动画），无风扇 `0`（失能）。
- 若屏端只保留动画控件，把 `VP_ICON_FAN` 那行写入删掉即可（`app_display_task.c` 一行）。

## 四、与旧行为差异（测试重点）

| 项 | 旧行为 | 新行为 |
| --- | --- | --- |
| 空载自停 | 仅逆变、**60s** | 旁路+逆变、**30min** |
| 过载 | >1100W 持续 5s 停机；仅文字提示 | >500W 声光报警；>700W 持续 10min 停机 |
| 电池过温 | ≥55℃ **锁死**进 FAULT，需断电重启 | ≥60℃ 可恢复降载，≤55℃ 自动解除 |
| 掉交流 | 立即全断并**清除输出请求**（须重按 AC） | 保留请求，自动转逆变；来电自动回旁路 |
| 安静时长 | 无整机关机定时 | 1h 无输出无充电 → 关机 |
| 时间显示 | 无估计时 `0 MIN`，旁路时空白 | 未接负载/无估计 `--`（旁路同样 `--`） |
| 屏上 OVERLOAD | 常亮 | 2.0s 周期闪动（与蜂鸣/报警灯同相） |
| Temp 图标 | 常亮、无迟滞 | 1.0s 闪动 + 5℃ 迟滞 |

> ⚠️ **两个需要现场确认的行为变化**：
> 1. **掉交流不再"3 声报警"**（`input_abort` 已删除），改为静默转逆变。若产线/售后以蜂鸣判断"掉电"，需同步更新判据。
> 2. **接入市电但电池已满时**，1h 后也会关机（"未给整机充电"成立）。若产品希望"插着市电就不关机"，需在 `idle_shutdown_check()` 增加"市电在位"排除项（一行改动）。

## 四之一、ERR 码表（2026-11 重新定义）

单一码表：`app_alarm.c` 里一张按优先级排列的表，查出最高优先级码，屏上显示 `ERRxx`（两位十进制）。
**新增告警只需在表里加一行 + 分配码**，不再有"两套编号 + 偏移"的拼接。

| 码 | 名称 | 触发条件 | 系统动作 | 恢复方式 |
| --- | --- | --- | --- | --- |
| **01** | BAT_COMM | MAX17263 连续 ≥10 次轮询失败 | 停机锁死 | 断电重启 |
| **02** | METER_COMM | HLW8110 任一通道持续无数据 | 停机/降级 | 断电重启 |
| **03** | BAT_INVALID | 电池快照无效 / 方向故障位 | 停机锁死 | 断电重启 |
| **04** | STORAGE | 存储/参数区异常（预留） | 降级提示 | — |
| **10** | BAT_OVP | 单体电压 ≥ `max_cell_mv` | 停充 | 电压回落 |
| **11** | BAT_UVP | 单体电压 ≤ `min_cell_mv` | 停放电 | 电压回升 |
| **12** | BAT_OCP | 充/放电电流超限 | 停机锁死 | 断电重启 |
| **13** | LOW_SOC | SOC < `low_soc`(10%) | 提示 / 禁止启动逆变 | 电量回升 |
| **20** | BAT_OTP | 电池 NTC ≥ 60℃ | 停充 + 停交流输出 | ≤55℃ 自动解除 |
| **21** | CHG_OTP | 充电器 ≥ 75℃ | 停机锁死 | 断电重启 |
| **22** | INV_OTP | 逆变器 ≥ 75℃ | 停机锁死 | 断电重启 |
| **40** | AC_INPUT | 输入有电压但不在 90~300V 窗口，持续 3s | 转逆变 | 市电恢复正常 |
| **88** | SELFTEST | 自检/全段显示 | 无（保留） | — |

优先级（同屏只显示一个码）：`01 > 02 > 03 > 12 > 11 > 10 > 20 > 21 > 22 > 04 > 13 > 40`

判定"是否锁死"用 `app_alarm_code_is_latched()`（01/02/03/12/21/22 返回 true）。

> 废弃项：原 `ERROR 01~03` + `ALARM 01~03 偏移 +7 → 08~10` 的双表机制已删除；
> 原瞬时提示 `ERR17`（电量过低禁止逆变）并入 **ERR13**。

### 待办（阻塞/未闭环）

1. **SP+4 库号偏移未实测** —— 若上机后 60s 自检期外电量仍不变色，需改 `VP_BATT_SOC_LIB` 偏移（备选 SP+2/+5）。

5. **硬件 I2C/NTC** —— MAX17263 通讯失败、三路 NTC 浮空，会掩盖电量与温度相关功能。
