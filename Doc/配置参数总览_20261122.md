# SmartBattBox 配置参数总览

> 生成日期：2026-11-22
> 适用固件：`Debug/SmartBattBox.bin` **74 052 B**（2026-11-21 20:04:00）
> 硬件：STM32F407VGT6 + MAX17263（电量计）+ HLW8110（计量）+ DWIN T5L（屏）

## 一、硬件拓扑速览

| 项目 | 值 |
|---|---|
| 电池 | **8S LFP**（标称 25.6V，满电静置 27.8~28.5V） |
| 充电器 | CV **29.2V**（3.65V/单体），恒流约 **6.1A** |
| 逆变器 | 额定 **1000W**（220V/50Hz 输出） |
| 电量计 | MAX17263，I2C1 @ `0x36`，分流电阻 **1mΩ** |
| 计量 IC | HLW8110 ×2（输入/输出），UART2/UART3 |
| 继电器 | CHG_IN(PD2) / CHG_OUT(PD3) / AC_CTRL(PD1) / INV_OUT(PD0) / INV_PRO(PD4) / INV_IN(PD7) |
| 风扇 | FAN1(PD10) / FAN2(PD11) |
| 电源自锁 | PB4（`DEV_POWER_OFF()` 拉低即断电） |

## 二、MAX17263 电量计配置

配置源：[Module/Inc/battery_config.h](../Module/Inc/battery_config.h) → `battery_cfg`

### 2.1 基本参数

| 字段 | 值 | 说明 |
|---|---|---|
| `rsense_uohm` | **1000**（1mΩ） | 分流电阻 |
| `design_mah` | **20000** | 设计容量（⚠️ 实际约 30Ah，见第五章） |
| `ichgterm_ma` | **200** | 充电终止电流 |
| `empty_mv` | **2500** | 空电点（2.5V/单体 → 整包 20.0V） |
| `recovery_mv` | **3000** | 空电恢复点 |
| `full_soc_thr_pct` | **80** | FullSOCThr（FQ 判满的 SOC 门槛） |
| `series_cells` | **8** | 串联节数 |
| `external_ntc` | **false** | 不用外部 NTC，用芯片内部 die 温度 |
| `ntc_100k` | false | — |
| `allow_uncharacterized` | **true** | 允许未做电池特性化（EZ 模式） |
| `model` | **NULL** | 无 OCV 模型表，靠 EZ 自学习 |
| `poll_timeout_ms` | **3000** | 单次轮询超时 |
| `profile_id` | **7** | 配置版本号（改 FQ/FullSOCThr 等需 bump 强制重配） |
| `battery_id` | **1** | 电池包 ID（换包需改） |

### 2.2 上报给应用的数据

| 字段 | 来源寄存器 | 用途 |
|---|---|---|
| `soc` | RepSOC | 显示 + 保护判据 |
| `vfsoc` | VFSOC | FQ 判满参考 |
| `soh` | SOH | 显示 |
| `voltage_mv` / `cell_voltage_mv` | VCell / AvgVCell | 欠压/过压保护 |
| `current_ma` / `avg_current_ma` | Current / AvgCurrent | 充电判满、过流保护 |
| `repcap_mah` / `fullcap_mah` | RepCap / FullCap | 容量学习 |
| `time_to_full_min` / `time_to_empty_min` | TTF / TTE | 时间显示 |
| `cycles_raw` | Cycles | 循环计数（0.01 次/LSB） |
| `fstat_raw` | FStat(0x3D) | bit7=FQ / bit8=EDet / bit6=RelDt2 / bit9=RelDt |

### 2.3 告警（ALRT 引脚 PB8）

| 寄存器 | 内容 |
|---|---|
| `VALRT` | 单体电压窗（min/max，20mV/LSB） |
| `TALRT` | 温度窗 |
| `CONFIG` | 使能 ALRT 中断输出 |

## 九、已知偏差与待校准项

| # | 项目 | 现象 | 建议 |
|---|---|---|---|
| 1 | **电池电流偏高 ~25%** | 充电算效率 110%（不可能）、放电 70%；`fullcap` 学习 23 370 mAh 而实际约 30 Ah | 用钳形表实测，修正 `rsense_uohm` 或 CGain |
| 2 | **`bat_uvp_mv` 等参数是死参数** | 改成 24000 时欠压仍在 20.0V 才动作 | 接上逻辑或从参数表删除 |
| 3 | **BAT/CHG NTC 间歇性跳变** | 10 秒内 ±20℃，三路同时跳 | 检查接线；固件加跳变过滤 |
| 4 | **过载告警无去抖** | 表测 130W 也亮 OVERLOAD | 加 300ms 去抖 |
| 5 | **物理兜底 1h 计时易被清零** | 充电器 re-bulk 时 `avgI` 冲高 | 容错窗 10s → 120s，或改累计计时 |
| 6 | **容量学习漂移** | fullcap 23 370 ↔ 32 445 mAh 间跳 | 修正电流标定后重新学习 |
| 7 | `design_mah` 20000 与实际不符 | 实际约 30 Ah | 改为实测值 |
